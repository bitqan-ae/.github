## What we do

- Electronic and PCB design, from schematic to design for manufacturing
- Firmware development and embedded systems design
- FPGA design and signal processing
- Antenna design, RF front ends, software defined radio, RF and audio modems
- Acoustic and radio real-time localization
- GNSS resilience against jamming and spoofing
- Secure systems: secure boot, key storage, on-device encryption, security reviews
- IoT devices built to run for years on small batteries
- Mechanical design and enclosures
- Productization consulting, from working prototypes to shippable products
